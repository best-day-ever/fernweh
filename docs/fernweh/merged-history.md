# Merged source history

This index expands the thematic [implementation map](enhancements.md). It
records original BDE reviews whose merge commit or source head is reachable from
the reviewed Fernweh component `main`. It includes release records, tests, build
repairs and upstream imports; **PR counts are not counts of distinct features**.
Merged work can also have been superseded by a later fix. Current behavior is
defined by source, protocols and the integration ledger.

Snapshot: 14 November 2026; parent `17b2efe1`, Client `20ca1fbf`, Linux Host
`ca113b5b`. Original PR numbers belong to `best-day-ever/plank*`, not the new
Fernweh repositories. Some original parent reviews require access to the private
BDE repository; the adjacent commit links use the Fernweh source repositories.
A “head” annotation means the implementation head is in Fernweh while the
original merge wrapper is not. This preserves an auditable ancestry claim
without claiming that every original merge commit was imported.

Included original reviews: Parent **118**, Client **76**, Linux Host **38** (**232** total).

The original parent immersive review is additionally represented by its
Client/Host/common-C/input-library implementation chain and a fresh Fernweh
parent integration; its original parent merge wrapper is not an ancestor of
this fork. See [immersive mouse](enhancements.md#immersive-mouse-merged-source-default-build-parity-open).

The machine-readable [evidence snapshot](merged-history.json) retains full
SHAs, classification and original merge times. Upstream/dependency rows are
credits and integration work, not new features attributed to Fernweh. Draft PRs
and rejected generic dependency proposals are excluded.
