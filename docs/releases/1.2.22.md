# BDE Fernweh 1.2.22 — shared sessions and connection recovery

This coordinated Client, Linux Host and broker release includes the fixes merged
through the first-connection recovery integration, plus the previously isolated
shared Mac desktop integration. Version1.2.21 was built for qualification but
was not promoted to deployment or client feeds.

## Client

- Open independent connections to several workstations with remembered sign-in.
  Updates wait until other application windows and workstation sessions close.
- Show connected people per workstation and a cyan active-desktop pointer during
  shared control. The pointer represents desktop activity, not a named pointer
  for every participant.
- Retry temporary worker-admission failures during display/login transitions,
  with bounded authentication grace and monotonic layout deadlines.
- Include the previous Windows installer-path repair, remembered device sign-in,
  session renewal, clipboard and scrolling fixes.
- Provide bounded, sanitized beta diagnostics only when the administrator enables
  the broker collection window. Diagnostics are disabled by default.

## Linux Host

- Keep shared input responsive while automatically authorized people join, and
  close completed consent panels. Arbitrate competing mouse motion with a short
  idle handoff and preserve drag ownership.
- Retry the specific transient NvFBC capture recreation failure during login
  modesets for up to five seconds. Other driver errors remain fatal.
- Retain workstation-authorized joining and existing authentication, desktop-lock,
  grant, clipboard and file-transfer restrictions.

## Broker and qualification

The broker adds authenticated per-stream presence with expiring heartbeats and
the opt-in diagnostics endpoint. Matching new Clients are required for presence.
Older Clients remain supported but do not report named presence.

The Mac package targets Apple Silicon and macOS 15 or newer with SDK 27. Windows
uses the authorized unsigned ALPHA MSI feed. Exact package hashes, build checks,
deployment receipts and remaining live-session acceptance belong with the
platform deployment record. Build/component checks alone do not establish
multi-user, tablet, audio or first-login hardware acceptance.

## Shared Mac desktop integration

Preserve the explicit, administrator-configured shared Mac desktop admission
path. Individual MFA/device/HBAC authorization issues a short-lived capability
bound to the Host certificate and local account; Linux keeps GSSAPI/PAM. The
relay validates the common policy without reading the broker-only signing key.
Presence and diagnostics coexist with Mac admission, with diagnostics disabled
unless explicitly configured. The Client preserves the active shared display
layout and the packaged SDL posted-pointer correction. Existing Mac Host
installation and operator acceptance limits remain recorded separately.
