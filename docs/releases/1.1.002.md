# 1.1.002 — Mac Wacom pressure forwarding

This Client-only release restores the raw HID Wacom session startup that was
lost when the optional SDL normalized pen path was added. On a compatible
Linux Host, the Mac Client now creates its Wacom transport when the Host
advertises raw tablet input and focus suspend. The two pen paths remain
mutually exclusive; `PLANK_MACOS_PEN_INPUT=1` still selects normalized pen.

The raw transport forwards the tablet's HID reports to the existing virtual
tablet on the Host. Linux Host 1.1.001 remains the matching release; its input
protocol and package are unchanged. The fix is scoped to the Client and does
not change broker admission, display handling, or the media protocol.

The Mac development build and bundled test suites passed on macOS 27. The
signed package and canary Flame pressure test are tracked in bde-linux T64.
