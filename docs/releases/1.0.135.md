# PLANK 1.0.135 (BDE fork) — Touch ID setup after OTP sign-in

After a new Fernweh user's first setup or an existing user's password and OTP sign-in, the Mac client can offer to register a local Secure Enclave key for future Touch ID sign-in. The user may decline and continue with password and OTP. Each Mac gets its own key.

The broker permits one passkey registration for five minutes after a fresh, device-bound OTP sign-in. It verifies device proof and writes to IPA with the user's Kerberos session ticket and existing self-service rights. The setup grant is not persisted. A repeated request for the same key is safe if an HTTP reply is lost.

The IPA policy for assigned Fernweh users enables password, OTP and passkey together. The patched IPA KDC remains required so OTP continues to work after a passkey is added. Linux Host 1.0.134 remains current.

## Packages

- macOS Client 1.0.135 (Apple Silicon, Developer ID signed and notarized).
- Broker from this release; bde-linux pins its exact commit and binary hashes.
- Linux Host 1.0.134 remains current.
