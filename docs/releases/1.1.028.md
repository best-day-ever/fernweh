# 1.1.028 — Stream window close cleanup

Client-only release candidate for Windows testing. The Linux Host and broker
are unchanged.

- Closing a stream window now disconnects its owned session, including after
  reconnect, so a hidden stream does not continue running.
- Includes the 1.1.027 launcher polish and toolbar shortcut.

The Windows x64 MSI is an unsigned internal test candidate. Windows audio,
Wacom, colour, multiple displays and device-session acceptance remain open.

Upstream PLANK, Client and Linux Host `main` were checked on 2026-09-29.
The Linux Host is already merged through its current upstream main. The
remaining upstream root/Client commits are the 1.1.025–1.1.027 audio
synchronization series, which upstream's handoff records as a rollback
checkpoint with crackle and video-hold defects. This candidate leaves that
series deferred pending a qualified upstream repair.
