# BDE fernweh 1.0.140 — smooth desktop sign-out handoff

When a person confirms signing out an idle workstation owner, the Mac client now keeps waiting through temporary remote admission denials while the old desktop and media worker exit. It obtains a fresh one-use broker admission token on each retry and connects to the greeter when it is ready. The wait remains bounded to 60 seconds. Admission denial outside this confirmed handoff still ends the connection.

The host and broker protocols are unchanged.

## Verification

- Mac development build and bundled Qt suites passed with no failures.
- Live two-user canary handoff is pending.
