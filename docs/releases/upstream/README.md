# Upstream release notes with colliding version numbers

BDE and Instinctual PLANK both published `1.1.003` to `1.1.006`. The parent
directory keeps the BDE notes for those versions, which match the packages
pinned in bde-linux. The Instinctual notes for the same numbers are kept here.
Instinctual notes without a BDE counterpart (`1.1.007`–`1.1.009`, `1.1.024`)
stay in the parent directory.
