# PLANK 1.0.128 (bde fork) — one person per workstation

## Changes

- Linux Host (`security.desktop_handoff`): a PLANK login finishes on the
  workstation. At the GDM greeter the account is signed straight in (one-shot
  root-only pass consumed by the new `pam_plank_handoff.so` in `gdm-password`;
  no second password prompt). Reconnecting to your own locked desktop unlocks
  it. Only one account streams at a time. Another account may sign out a
  desktop owner who is not connected, after confirming in the Client
  (best-day-ever/plank-host-linux#2, feature flag `0x400000`).
- Mac Client: "Workstation in use" confirmation to sign out an owner who is
  not connected; "<owner> is connected" refusal; automatic reconnect after the
  sign-out (best-day-ever/plank-client#10).
- Remote access sessions are bound to this device and last 30 days
  (best-day-ever/plank#18, plank-client#11), first shipped in this Client.

## Packages

- macOS Client: macOS 13+, Apple Silicon, signed/notarized DMG, built from
  main on the local Mac builder (GitHub Actions unavailable).
- Linux Host RPM `plank-host-1.0.127-0.bde_single_session.1` (branch build
  of the same Host source); other packages are not rebuilt for this version.
