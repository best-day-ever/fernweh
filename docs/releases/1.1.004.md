# 1.1.004 — Fernweh clipboard entitlements

The Linux Host can require operating-system group membership separately for
text clipboard sync and file clipboard transfer. It checks the authenticated
account for every launch and resume, denies on NSS lookup failure, and reports
the effective text and file policy to the Client. File transfer continues to
require text clipboard's authenticated session epoch.

The Mac Client accepts a Host narrowing either clipboard feature for one
session. BDE configures the two groups through FreeIPA, with both grants on by
default for all users registered when the groups were created and for new
portal-created users. Administrators can remove either grant on a user's portal
page without changing machine access.

The Host's generic defaults remain unchanged unless an administrator names
entitlement groups and enables file clipboard in `host.conf`.
