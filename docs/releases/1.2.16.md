# BDE fernweh 1.2.16

Windows updates now convert the downloaded MSI path to native Windows
separators before invoking Windows Installer. Qt-style forward slashes passed
the package integrity and identity checks but caused installation to fail with
error 1619. Native, forward-slash and mixed paths are covered by process-launch
regressions, including spaces and Unicode.

Clients containing the previous updater need one manual MSI installation to
receive this fix; the broken helper belongs to the already installed client.
Install the new MSI over the existing installation and keep the saved settings
and account data. Later updates use the repaired helper.

This is a Windows-only release. The Mac feed remains on 1.2.15. Broker and
Linux Host binaries, session policy and ALPHA signing policy are unchanged.
