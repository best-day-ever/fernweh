# BDE fernweh 1.0.141 — separate Mac monitor windows

Mac sessions now open one fullscreen window per selected display when using saved older Match my displays layouts. Each window shows its own remote monitor with correctly mapped input. The display planner also prepares secondary windows for a windowed launch and synchronizes native fullscreen transitions with the session.

Dragging a remote window between screens preserves the held mouse button. macOS now enables SDL automatic capture, and the client routes captured movement beyond the original window into the adjacent presentation window. Displays have separate Spaces remains required for native fullscreen on separate monitors.

This release includes the merged 1.0.140 sign-out handoff fix and the 1.0.139 updater. Host and broker protocols are unchanged.
