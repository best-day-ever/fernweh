# 1.1.044 — Mac display windows and desktop recovery

Client-only release; the Host and broker do not need an update.

- Preserve the display planner's per-monitor window selection instead of
  overriding arrangements with the older layout counter. Two selected external
  screens also work when a connected laptop panel is excluded.
- Keep both Mac windows visible and cropped to their own remote display when
  starting or leaving fullscreen. Size each normal window for its own display.
- Retain the selected primary display when applying a profile during a session.
- Retry ordinary connection failures while the Host worker starts the user's
  desktop. Actual TLS identity rejections remain fatal and still prevent
  credential transmission.
- Allow normal one-frame-per-second idle capture without repeatedly displaying
  a waiting warning.

Verification includes native Mac builds and bundled suites, synthetic TLS
refusal/closure/timeout and identity-rejection cases, presentation geometry,
and a physical two-UHD-display qualification. The hardware observations and
deployment receipts are retained in the private operator runbook.
