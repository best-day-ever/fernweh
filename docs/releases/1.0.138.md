# PLANK 1.0.138 (BDE fork) — Fernweh toolbar auto-hide

The Fernweh streaming toolbar now hides after five seconds of pointer inactivity when unpinned, including when the pointer remains over the toolbar. Moving the pointer or using a control restarts the timer. Pinning keeps the toolbar visible; an active button drag or unanswered screen-change prompt also keeps it open.

## Package

- macOS Client 1.0.138 for Apple Silicon. The Linux Host and broker are unchanged.

## Verification

- Mac client development build and bundled Qt suites passed on the Apple Silicon builder.
- A live pointer and pin/unpin check with the packaged app remains required before calling the UI behavior qualified.
