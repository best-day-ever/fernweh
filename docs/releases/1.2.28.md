# Host1.2.28 — Studio sharing entitlement

The optional collaboration_join_group restricts joining another owner's desktop
to current NSS group members, including when owner approval is disabled or given.
Requests, support unlock and sharing-grant launch all recheck this entitlement.
Own desktop access and owner controls remain available to nonmembers.

This Host release retains1.2.27's explicit Unlock and join and automatic relock
behavior. Fernweh Client1.2.27 implements the matching user action. BDE grants its reviewed permanent studio roster direct joining and unlock.
Temporary artists require owner approval to join an unlocked desktop and cannot
unlock another owner. The optional stricter join-group gate remains unconfigured.

collaboration/greeter tests, supervisor/session-context syntax and119 root CI
tests. Full Rocky9.7 package and installed acceptance follow before deployment.
