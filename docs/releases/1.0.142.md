# BDE fernweh 1.0.142 — complete macOS app branding

The packaged Mac app now uses **BDE fernweh** in the macOS application menu,
including its Hide and Quit commands, and as its executable name. The window,
Dock, update controls, and installer already used that product name. The bundle
identifier and settings namespace remain stable, preserving existing sign-ins
and preferences. Client and broker protocols are unchanged.

This release includes the 1.0.140 sign-out handoff and 1.0.141 Mac multi-monitor
fixes. Clients on 1.0.139 or later can install it using the broker's in-app
Update control. Older clients need one manual installation of an updater-bearing
release.

## Verification

- Run the Mac package's signing, notarization, Gatekeeper, bundled dependency,
  and offscreen version gates from a clean merged source tree.
- Install the release through the broker's Update control and verify the app
  menu reads BDE fernweh after relaunch.
