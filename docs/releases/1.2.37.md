# 1.2.37 — Coordinated upstream integration candidate

This candidate combines the reviewed PLANK 1.4.18 frontend, Native10 capture,
transport and optional metrics work with Fernweh's platform adapters. The
Client keeps saved display selection, crops, shared views, Apply/Keep,
clipboard grants and exact-format fallback. Windows retains its native
renderer/audio adapter; Mac sessions use the Qt/native media owner.

Local disconnect/toolbar shortcuts remain available when the remote input
queue is busy. Linux capture uses one shared image layout across its compilers;
large-frame transport retains bounded buffering and checks actual socket
receive capacity. Optional metrics stay disabled by default. Direct-only builds
remain the default; configured broker products are explicit builds.

Native source, Mac/Windows Client, Linux controlled-loss and uninstalled RPM
checks pass as recorded in [the integration receipt](../fernweh/review.md).
Installed-session and hardware acceptance remain required before promotion.
This file reserves the next immutable package version; it does not announce a
published release. Final packages must be rebuilt from the merged PR commits,
independently checked, and deployed through the normal guarded rollout.
