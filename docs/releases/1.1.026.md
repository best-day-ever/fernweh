# 1.1.026 — Toolbar shortcut

Client-only release. The Linux Host stays at 1.1.025.

- **Ctrl+Alt+Shift+T** shows or hides the stream toolbar (Control+Option+Shift+T
  on a Mac). Before, the toolbar only appeared after holding the pointer at the
  very top of the window for a second, an edge that macOS fullscreen also uses
  for its menu bar. A toolbar opened with the shortcut auto-hides after five
  seconds without pointer activity unless it is pinned, like the edge reveal.
  The shortcut also works in immersive keyboard mode.
- The tip shown while a stream starts names the toolbar shortcut next to
  Ctrl+Alt+Shift+Q (disconnect).
- The macOS capture choice for LAN bookmarks no longer says "Experimental",
  matching upstream.
- Test and gate fixes: the Mac build now also runs the bookmark host-choice,
  Wacom transport and client policy suites; a stale Host log test expectation
  was corrected.
