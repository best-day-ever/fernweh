# PLANK 1.0.126 (bde fork)

## Changes

- Passkey (Touch ID) sign-in for remote access (bde-linux
  `docs/plank-broker.md` section 13):
  - Broker: `method: "passkey"` sign-in through FreeIPA's PA-REDHAT-PASSKEY
    preauthentication, with synthetic challenges for unknown users
    (best-day-ever/plank#11).
  - Linux Host: `gssapi_required_indicator` accepts a list, so both `otp`
    and `passkey` tickets are admitted (best-day-ever/plank#12,
    plank-host-linux#1).
  - macOS Client: the bundled `plank-passkey` helper keeps a Secure Enclave
    P-256 key that Touch ID or the Mac password unlocks. Remote sign-in uses
    it when this Mac has a key for the user, and falls back to password +
    authenticator code otherwise. Settings sets the key up and shows the
    mapping for the administrator (best-day-ever/plank#10, plank-client#7).
- macOS Client: one request per connection to the PLANK host, which fixes
  brokered connects (plank-client#6).
- macOS Client: per-workstation display setup for remote hosts
  (plank-client#8).

## Packages

- macOS Client: macOS 13+, Apple Silicon, signed/notarized DMG, rebuilt from
  main on the local Mac builder (GitHub Actions unavailable). The
  `plank-passkey` helper is signed with the app (hardened runtime, no
  entitlements).
- Linux Host / Linux Client / macOS Host: not rebuilt for this version.

## Validation scope

All gated Client suites pass, and so does the helper's signature-format
self-test (OpenSSL verification with a software key). A brokered passkey
login was verified live against IPA and a host. Signing with Touch ID in
the packaged Client is the remaining acceptance check.
