# 1.1.045 — Stable display transitions

Includes the Mac display and desktop recovery changes in 1.1.044, plus a
follow-up found during physical two-monitor qualification. Changing saved
screen settings during recovery could make the client wait for a layout it
had never requested. Polling now preserves the submitted plan while using
fresh host capture dimensions. Apply Screens still submits the new profile.

Client-only release; no Host or broker update is required for these changes.

Verification covers two actual UHD monitors, separate fullscreen and normal
windows, transport retry through a forced worker restart, idle capture and
the pending-layout regression. Exact operator receipts are retained privately.
