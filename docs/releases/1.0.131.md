# PLANK 1.0.131 (bde fork) — display arrangement boot fix

Includes the display arrangement release in 1.0.130.

## Fix

- Enable the workstation host from `graphical.target`. The host still starts after the display manager, but it no longer creates an ordering cycle with BDE firstboot, which runs after `multi-user.target` and before GDM. Existing installations must remove the old `multi-user.target.wants/plank-host.service` link before enabling the updated unit.

## Packages

- Linux Host 1.0.131 RPM for Rocky Linux 9.7.
- macOS Client 1.0.131 for Apple Silicon, macOS 13+; its client code is unchanged from 1.0.130.
- Broker: unchanged.
