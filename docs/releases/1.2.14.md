# BDE fernweh 1.2.14

Integrates upstream PLANK main through `b3d3235c` and Client main through
`7edb5c3b`, preserving the Fernweh broker, device sessions, updater, display
arrangement, per-profile bitrate, collaboration and Windows input support.

Windows clients now advertise their implemented text and file clipboard
capabilities. Earlier Windows releases contained the native implementations but
negotiated neither capability, so an authorized Host could not enable them.
Authenticated Host policy still removes capabilities the account does not have;
collaboration guests remain unable to use either clipboard path.

Selected upstream improvements include native scaling for new bookmarks,
clearer Internet reachability and on-demand ping details, and the shared client
identity implementation. Existing bookmark choices and saved credentials remain
in their established namespace. There is one shipping implementation for each
feature: BDE display arrangement and bitrate controls remain authoritative.

The Mac package retains Fernweh's SDL session frontend through a build-only
configuration. The upstream Qt frontend is present and tested separately, but
its current feature set does not cover Fernweh's file picker, collaboration,
display reconfiguration and reserved session shortcuts. Do not enable it in a
Fernweh release until those contracts have equivalent runtime coverage. The
shared Mac build follows upstream's macOS 15 minimum and SDK 27 requirement;
BDE distribution remains a signed/notarized DMG with the existing updater.

This is a Client release. Linux Host 1.1.047 and the deployed broker remain
unchanged: no Host protocol or dependency update is required.

Qualification is recorded with the BDE deployment pins and private build
receipts. Source integration alone is not a published installer or hands-on
Windows-to-Linux clipboard acceptance.
