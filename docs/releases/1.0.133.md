# PLANK 1.0.133 (bde fork) — Fernweh desktop handoff recovery

Includes the Linux display arrangement release and exact display restore in 1.0.132.

## Fix

- Fernweh retries the brief zero-output topology snapshot that XRandR can publish while switching modes. Other malformed topology documents remain errors.
- During an explicit GDM-to-desktop handoff, Fernweh retries early broker or host admission refusals for at most 15 seconds, with two seconds between attempts. Outside this handoff, authentication refusals remain terminal.
- Fernweh quietly refreshes workstation availability after a stream ends, so the host worker restart does not leave canary showing as offline until someone presses Refresh.

## Packages

- macOS Client 1.0.133 for Apple Silicon, macOS 13+.
- Linux Host 1.0.132 RPM remains current; no host code changed.
- Broker unchanged.
