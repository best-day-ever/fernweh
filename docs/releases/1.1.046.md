# 1.1.046 — Authenticated display capabilities

Pin launch capabilities from authenticated output topology. Public discovery
does not include optional display-arrangement or file-clipboard capabilities;
after launch consumes its authentication token, background polling can replace
the shared discovery flags. Reconnect now uses fresh authenticated topology,
and display planning and launch negotiation share the same capability snapshot.
Pending display transitions retain their submitted snapshot.

This fixes unintended fallback to the older dual-screen protocol. Explicit
saved older-workstation profiles retain their selected behavior. It does not
claim to fix a separately stalled Linux desktop compositor.
