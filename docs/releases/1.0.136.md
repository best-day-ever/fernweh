# PLANK 1.0.136 (BDE fork) — desktop handoff and display recovery

Fernweh now handles the transition from the login screen to a user desktop without leaving a black or unusable workstation screen. The Linux host keeps an active scanout while it applies and restores a remote display arrangement, recovers a stale greeter lease, and excludes transient zero-sized capture placeholders from the output topology. The Mac client retries a temporarily empty topology at connection startup and a bounded desktop handoff even when the handoff notice is lost. Broker reconnect diagnostics identify the failure class without logging credentials.

## Packages

- Linux Host 1.0.136 for the pinned Rocky Linux 9.7 workstation image.
- macOS Client 1.0.136 for Apple Silicon.
- Broker remains at the previous release; its protocol and deployment are unchanged.

## Verification

- Host display and greeter recovery tests and the Rocky Linux host RPM package gates passed.
- Mac client build and included test suites passed.
- On the canary workstation, a remote login reached the user desktop, GNOME could open and tile a window, and disconnect restored the physical display as the sole monitor. The repeated monitor geometry assertions seen during the incident did not recur.
