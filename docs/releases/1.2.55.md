# Fernweh 1.2.55

- The Linux Host retries a temporarily unavailable X11 cursor image while audio, video and pointer position keep updating.
- A workstation marked offline can be tried immediately. The broker checks it again before granting access. If the status refresh fails, the Client shows that status is unavailable.
- The Client stops its loading animation and releases the connection screen after the stream ends.
- This release carries forward the Linux display-restoration and KScreen fixes and the Mac session teardown fix.
