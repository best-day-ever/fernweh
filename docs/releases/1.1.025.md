# 1.1.025 — Instinctual PLANK 1.1.024 import

BDE fernweh now includes the upstream PLANK 1.1.024 Client and Linux Host
changes on top of the BDE 1.1.006 line. Upgrade the Host and Mac Client
together, as for every BDE release since 1.1.001.

## Wacom

- The Linux Host releases a held pen contact when raw tablet forwarding is
  suspended (focus loss, app or Space switch) and verifies the release within
  a bounded time, without recreating the virtual tablet.
- The Mac Client reconciles raw Wacom focus across fullscreen Spaces and holds
  new tablet reports until the Host has released the previous contact.
- On launch the Mac Client asks for Input Monitoring only when a supported USB
  Wacom is attached, so pressure works on the first stream. A new
  Permissions pane in Settings shows keyboard, tablet and microphone access.

## Occupancy

The Host computes occupancy from lock-free snapshots, so the broker's busy
probe and LAN discovery stay responsive while a stream tears down. The same
nameless value is published as `PlankWorkstationBusy` (broker) and
`PlankOccupied` (LAN bookmarks, shown as **In Session**). The optional
`publish_session_user` account name stays off on BDE workstations.

## Display and other Client changes

- The Mac Client uses a display's current pixel size when macOS reports no
  native mode, instead of failing display discovery.
- The bookmark editor's physical-display layout is named **Match Host**.
- The toolbar no longer applies the obsolete notch offset in fullscreen.
- The Client's app icon uses the upstream macOS Client artwork (same PLANK
  image in the standard macOS rounded-square shape).
- Upstream microphone/camera negotiation for Mac Hosts is included but unused
  with Linux Hosts; BDE's launch does not ask for microphone access.

## Not included

Upstream's 1.1.025–1.1.027 audio-sync checkpoint is not part of this release:
upstream records it as a rollback checkpoint with open playback defects.
The upstream `.pkg` Client installer is not used; BDE keeps its signed DMG
and broker update feed. Broker admission, display policy and wire-bit
allocations are unchanged.
