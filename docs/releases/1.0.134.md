# PLANK 1.0.134 (bde fork) — GDM greeter recovery

Includes Fernweh 1.0.133 and its first desktop handoff recovery.

## Fix

- When GDM reports an active greeter but its X server has disappeared after a user session ends, the Linux host waits 20 seconds for normal recovery, then restarts GDM with a bounded timeout.
- The supervisor checks that no user desktop, display lease, qualification, or pending display transition exists before restarting GDM. It makes at most two attempts for a failed handoff.
- A normal remote disconnect still leaves the desktop session running and locks it after the reconnect grace period.

## Packages

- Linux Host 1.0.134 RPM for Rocky Linux 9.7.
- macOS Client 1.0.133 remains current; no client code changed.
- Broker unchanged.
