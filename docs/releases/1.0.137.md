# PLANK 1.0.137 (BDE fork) — reliable desktop handoff

The first 1.0.136 canary end-to-end check found two remaining failures after the GDM login: the broker reused a cached offline probe while the new desktop worker started, and the Mac client displayed that transient response as a sign-in failure. The broker now re-probes on an explicit connect, and the client retries only a genuine offline-unavailable response during its bounded handoff window. Other denial reasons still fail immediately.

The Linux host now gives a display lease carried from GDM to the user X session a 30-second activation window. If no desktop stream connects, the supervisor restores the physical display. A successful stream activation keeps the lease until release or worker failure.
