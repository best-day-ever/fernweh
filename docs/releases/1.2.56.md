# Fernweh 1.2.56

- Linux logs the X11 error when it cannot get a cursor image. The stream and pointer position continue while the Host retries the image.
- Linux handles the workstation's sign-in requests independently of display cleanup. If that connection closes, the Host recreates it.
- The Client identifies a failed workstation connection without implying that the artist's account or sign-in was rejected.

An isolated Xorg test reproduced a cursor that was still assigned to a window after the X11 client that created it had closed. XFixes returned BadAccess for the image while pointer position remained available. A new cursor on the same window restored image capture.
