# BDE Fernweh 1.1.040

Integrates upstream PLANK 1.1.039 through `38e00a5`, retaining BDE broker authentication, device sessions, desktop handoff, display layout, clipboard policy and idle capture.

- Wacom reconnect/focus recovery, retained Linux virtual tablets, reliable input backpressure and GPU downscaling improvements. Update Host and Client together.
- Windows ALPHA clients check the independent pinned-broker feed and can install unsigned MSI updates. The download must match its version, size, SHA-256, product name and upgrade family; Windows still asks for normal elevation. Installation waits for workstation sessions to end and retains local settings. Older Windows clients need this MSI installed manually once.
- First account setup no longer has a seven-day password-age deadline. A starter password still requires a personal password and authenticator setup; entitlement and account checks remain active.
- Mac distribution retains the signed/notarized DMG and macOS 13 deployment target, preserving the existing in-app update path.

Package qualification and live acceptance are recorded separately. Automated tests do not establish real pen pressure, audio synchronization or workstation hardware acceptance.
