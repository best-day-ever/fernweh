# 1.2.38 — Windows immersive mouse

The Windows Client adds the live **Mouse** toolbar toggle and
**Ctrl+Alt+Shift+M** for immersive mouse mode. It starts off each session and
requires a Linux X11 Host advertising ordered pointer capture. It is unavailable
to collaboration guests and older Hosts.

While enabled, unaccelerated movement continues across viewport edges and button
releases, including keyboard-started tools. Explicit release resynchronizes with
the Host before ordinary pointing resumes. Focus loss, reconnect, display changes
and tablet takeover cancel capture. Disconnect and toolbar shortcuts remain local.

This Windows ALPHA update has native broker-enabled and direct-only build and
component coverage. Package and installed-upgrade checks precede feed promotion;
physical Windows streaming and full Blender/Unreal/tablet acceptance remain open.
Existing Mac and Host packages remain independently pinned.
