# BDE Fernweh 1.2.17 — first-notch scrolling on Linux

The Linux host establishes the virtual mouse's X11 scroll baseline before each
nonzero wheel report. Moving the pointer and then scrolling no longer loses the
first notch in applications that reset cumulative scroll state when the input
source changes. Both axes retain their original high-resolution reports and
legacy-detent accumulation. Absolute positioning, buttons and drag behavior
remain on their existing paths.

This is a Host-only release. Client update feeds and broker binaries do not
change. Native application qualification and package evidence are required before
publishing the workstation package pin.
