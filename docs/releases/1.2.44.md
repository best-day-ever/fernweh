# Fernweh 1.2.44 — on-demand connection diagnostics

Updated signed-in Clients answer an administrator-requested connection test in
about two minutes. Independent UDP sampling measures packet loss, RTT and jitter
while bounded HTTPS upload/download tests measure goodput and delay under load.
Reports include raw measurements, available interface/error counters, DNS/API
and endpoint scheduling/CPU evidence, with an explained score or an explicit
inconclusive reason. See the [operator guide](../fernweh/diagnostics.md).

Each bandwidth direction is capped at200Mbit/s, ten seconds and250MB. Test data
is generated and discarded; no employee file payload is used. Tests run one at a
time only on request. Sign-out, opt-out and application exit cancel participation.
Ordinary automatic logs remain independent from these active tests.

Multiple Client windows sharing a sign-in each return their own recent log tail
when paired with an updated receiver. This extends the existing private, bounded
log collection and retains compatibility with older Clients/receivers.

The Linux Host remains the separately qualified1.2.43 capture release. This
release imports no additional upstream changes. Native packages and installed
acceptance are recorded separately; source publication alone is not deployment.
