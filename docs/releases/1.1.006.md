# 1.1.006 — Fernweh workstation busy status

The remote host list shows **Busy** when the Linux Host already has a session,
has reserved a launch, or has an attached desktop owner. The Host publishes
only a coarse busy flag. The broker preserves the existing certificate pin and
reports unknown status when it cannot verify the Host. Connect authorization
and the one-person-per-workstation admission rule remain unchanged.

The broker field is optional so older clients continue to work. The Mac Client
shows a busy label while retaining its existing Connect action for authorized
handoff and sign-out flows.

Rocky 9.7 Host packaging may use three native x86_64 transport throughput
trials for the exact compiled release test executable when timing is unreliable
under Mac x86 emulation. The builder checks the executable SHA-256 before
accepting that qualification and still runs all other transport and package
gates. The native trial log is retained with the release evidence.
