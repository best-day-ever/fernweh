# BDE Fernweh 1.1.042

An independently authenticated person can request to join an occupied Linux
desktop. The owner can decline, allow view-only access, or allow keyboard/mouse
interaction, then change permission or disconnect each guest while sharing.
Permission controls suspend guest input before appearing. Lock, logout, owner
departure and loss of the consent helper revoke guest access.

Guests inherit the primary user's existing monitors and capture geometry.
Their bookmark layout, window size and departure cannot reconfigure the Host's
display arrangement. Guest clipboard, files, pen, raw HID, microphone and camera
forwarding are disabled in both roles. Host input checks remain authoritative.
Concurrent streams share the fixed UDP listener with independent authentication,
transport tokens, connection state, rate policies and fixed MTUs.

The Mac Client also preserves the file-transfer improvements available through
Finder copy/paste and the streaming toolbar's **Files…** button for ordinary
owner sessions. The existing Linux Host file protocol and per-user grants
continue to apply.

- Open the destination folder remotely, reveal the toolbar, choose **Files…**,
  and select local files or folders. After **Files sent**, press **Ctrl+V** in
  the remote folder. The picker leaves the local clipboard intact.
- Finder **⌘C**, followed by remote **Ctrl+V**, supports immersive keyboard mode
  and reuses an already staged selection without retransmission.
- To receive files, copy them remotely, wait for **Files received**, then paste
  in Finder with **⌘V**. Newer local clipboard contents and changed stream focus
  are preserved.
- Crossed offers yield and retry the saved selection. Malformed or silent peers
  cannot leave transfers waiting forever, and remote URLs are not reflected
  back as new local offers.

Regular files and folders use the existing PCF2 protocol. Links, special files,
resource forks and extended attributes remain outside that protocol. Text and
file-transfer grants remain separate.

Automated Mac/Host policy, input, encrypted transport and package qualification
are recorded with the release artifacts. Paired Finder/Linux and two-person GPU
acceptance require live desktop checks; package builds alone do not prove them.
See the [collaboration protocol and acceptance contract](../../protocol/collaboration.md).
