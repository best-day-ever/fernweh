# 1.1.042 — collaboration candidate

This candidate adds owner-consented collaboration to the Linux desktop Host and
Fernweh Client. An independently authenticated user can request to join an
existing desktop. The owner can decline, allow view-only access, or allow desktop
interaction, then revoke or change the guest's permission while sharing.

Guests use the primary user's existing monitors and capture geometry. Their
bookmark layout, window size and disconnect cannot reconfigure the Host's
display arrangement. Guest clipboard, file transfer and device forwarding are
disabled. Host permission checks apply independently of client controls.

Concurrent native streams share the fixed Host UDP listener with separate
one-use transport tokens and per-connection state. The broker retains ordinary
authentication, host assignments and separate source-bound relay leases.

The protocol and required acceptance checks are documented in
[collaboration](../../protocol/collaboration.md). This is a candidate under
qualification, not an announcement of deployment or completed hardware tests.
