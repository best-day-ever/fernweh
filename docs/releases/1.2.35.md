# 1.2.35 — Manual Linux desktop login

Linux Host now keeps automatic GDM sign-in and automatic owner unlock behind
`desktop_auto_login`, disabled by default. An admitted Fernweh stream shows the
normal Linux login or lock screen. Signing out of Linux can no longer be undone
by a reconnect when this policy is disabled.

`desktop_handoff` still permits an explicitly confirmed sign-out of an idle
desktop owner. Desktop ownership, collaboration, broker authentication,
remembered Client sign-in, driver requirements and video transport are unchanged.
The fleet controller must also remove its optional GDM handoff PAM entries when
automatic desktop login is disabled.

This is a Linux Host release. Existing Mac and Windows Clients remain compatible.
