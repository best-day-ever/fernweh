# Fernweh Windows Client 1.2.46

The Windows Vulkan renderer now honors the color range tagged by the
decoder. Limited-range 4:2:0 streams keep their black and white levels
and saturation. Full-range 4:4:4 streams retain their existing mapping.
An untagged stream still uses the requested full range.

On a native Windows Vulkan chart readback, preserving the 4:2:0 metadata
restored 8-bit black and white from 16 and approximately 235 to 0 and 255.
The full-range HEVC 4:4:4 control matched pixel for pixel.

This release targets the Windows Client update feed.
