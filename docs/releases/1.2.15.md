# BDE fernweh 1.2.15

Windows now uses a persisted, nonexportable device key for the broker’s existing
remembered-device sign-in. Earlier Windows clients saved an unbound temporary
session because device signing was connected only to the Mac helper. An existing
Windows login needs one fresh password and second-factor sign-in to bind it;
passwords and second-factor codes are never saved. A successful username is
remembered per broker, including after sign-out or session expiry. Explicit
sign-out still revokes the saved session. Device-key failures are retryable and
never silently downgrade a bound session to unsigned requests.

Remote access renews its initial lease immediately before desktop preparation,
then schedules renewals from the actual expiry returned by the broker. The old
first renewal could miss the initial 30-second lease while preparing a desktop.
Reconnect and authentication generations prevent old replies from clearing a
new session, including a reconnect to the same workstation. Expiry and renewal
failures leave a visible reason in the launcher.

This release preserves the upstream integration and clipboard fixes in 1.2.14.
The Mac minimum remains macOS 15. Linux Host and broker binaries and their
session policy are unchanged. Remembered sessions remain subject to ticket
renewal limits, access revocation and explicit sign-out.
