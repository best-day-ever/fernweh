# 1.1.005 — Fernweh combined final release

This release combines the 1.1.003 input reliability and Mac immersive keyboard
changes with the 1.1.004 IPA clipboard and file transfer entitlements. It pins
the merged Client and Linux Host sources from 1.1.004 without changing their
feature behavior. See the 1.1.003 and 1.1.004 notes for the individual changes.

The Host must have its virtual keyboard and mouse ready before serving a
session. Mac immersive mode forwards ordinary shortcuts while the stream is
focused, with Ctrl+Alt+Shift+Z as the session escape. Clipboard and file
transfer are governed by separate IPA group grants.

The original intermittent video-only input failure was not reproduced
deterministically, so the precise loss point is still unknown. Physical Mac
shortcut acceptance and a live cross-device transfer remain user-session
checks.
