# BDE Fernweh 1.1.041

Windows clipboard and tablet input now use the existing authenticated Host protocols.
The Linux Host and Mac release remain at 1.1.040; this Windows update needs no Host upgrade.

- Copy and paste Unicode text in either direction with the usual Ctrl+C / Ctrl+V.
  Clipboard access respects the Host's per-user clipboard grant and stream focus.
  Busy clipboards retry; paste waits for queued clipboard chunks under transport pressure.
- Copy local files or folders in Explorer and paste in the remote file manager. Files
  copied on the remote desktop are staged on Windows and can be pasted in Explorer.
  File transfers require the separate Host file-transfer grant. Received files must
  be pasted before disconnecting: staging belongs to the stream. Local fixed/removable
  drives are supported; network shares, links and Windows-incompatible names are rejected.
- Windows supports USB Wacom raw HID forwarding, with Windows Ink pen fallback for
  drivers/devices that do not expose usable raw collections. The fallback carries
  pressure, tilt, eraser and pen buttons; device-specific pad, wheel and touch support
  requires successful raw forwarding. See [Windows tablet input](../../apps/client/docs/bde/windows-tablet.md).

Existing 1.1.040 Windows clients update from Settings → Advanced Settings → BDE fernweh
updates → Check for updates. Disconnect before installing and approve Windows elevation.
Older clients first install the updater-bearing MSI. The ALPHA MSI is unsigned and
continues to use exact hash, size, version and MSI-family validation.

Native build/component tests and physical hardware acceptance are separate. The build
machine has no Wacom attached; model-specific pressure, ExpressKeys, rings, touch,
focus/reconnect and driver compatibility require physical qualification. No physical
Wacom acceptance or live Windows-to-Linux application transfer is claimed by unit tests.
