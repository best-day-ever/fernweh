# PLANK 1.0.130 (bde fork) — workstation display arrangement

## Changes

- Linux Host: lease and restore a requested physical plus virtual display arrangement for a remote session, including recovery after a supervisor restart. Hybrid boot preparation leaves the physical display usable when inventory is unavailable.
- Linux Host: pack separately sized output captures into one encoder canvas when the requested desktop exceeds the encoder's width limit. Input and cursor coordinates stay tied to the desktop arrangement.
- Mac Client: choose the workstation display arrangement from the detected Mac displays. The session and renderer follow the negotiated output topology.
- Protocol: display arrangement extension `0x8000000` and packed-capture contract, with versioned test vectors.

## Packages

- macOS Client 1.0.130 for Apple Silicon, macOS 13+. Build, signing and notarization are release gates.
- Linux Host 1.0.130 RPM for Rocky Linux 9.7. The canary is the deployment target; its physical display must restore after each qualification run.
- Broker: unchanged.
