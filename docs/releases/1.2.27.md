# Fernweh1.2.27 — Unlock and join for authorized support

An explicitly configured support group can now unlock an existing locked
workstation desktop and join it without the owner returning or losing their
applications. Host policy defaults off. Ordinary automatic joining does not
grant remote unlock authority.

The Client offers Unlock and join only on an explicit authenticated Host offer.
The Host rechecks support membership, the attested active user and the exact
observed desktop generation before logind unlock. It audits identities/outcome
without secrets. Cancel does not unlock; changed targets and denied permissions
fail closed. Existing grant/channel and owner display-layout restrictions remain.

The final guest disconnect relocks a support-unlocked desktop. Abandoned joins
have a bounded safety relock; a private supervisor guard relocks the exact
session if its worker exits. Fresh owner authentication clears support protection.

Validation before packaging:31 native Linux collaboration/greeter tests and
supervisor/session-context syntax;24 portable Host tests;38 Mac Qt
invocations/767cases;119 root CI tests and privacy checks. Full Rocky9.7/Mac
package gates and installed acceptance are recorded separately before deployment.
