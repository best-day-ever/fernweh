# BDE Fernweh 1.1.033

Integrates upstream PLANK through `66f5c2a` and brings the Mac client and Linux
Host forward with the BDE changes already included in the Windows candidate.

- Mirrored Wacom tablets disable Xorg pressure recalibration so an initial
  nonzero pressure report does not suppress tip clicks. Physical tablets keep
  their normal driver policy. The setting takes effect in a new Xorg session.
- Client includes the guarded audio playback changes from upstream 1.1.030,
  stream-window Close handling, and the Windows stable monitor identity fix.
- Host retains BDE admission, clipboard grants, display modes and idle capture.

Build and deployment qualification is pending. Real audio listening, Wacom
pressure and multi-display acceptance require hands-on sessions. Windows
packages remain unsigned internal test candidates without an update feed.
