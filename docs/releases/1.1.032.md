# BDE Fernweh 1.1.032

Windows x64 test installer for the display profile fix in Client #46 and PLANK #66.

On Windows, the display setup uses stable monitor identities, but the streaming session previously rebuilt the same monitors with size-only identities. That could discard a saved disabled-monitor choice and request a second output anyway. The session now uses the setup identities; a uniquely sized monitor can still match when Qt and SDL report different scaled desktop coordinates. An ambiguous match stops the launch with a display-change message instead of silently enabling extra outputs.

An upgrade from the previous Windows candidate exited successfully on the Windows test machine; the installed 1.1.032 executable matches the staged executable byte for byte and the Start menu entry is present.
- Root CI passed 60 tests with one skip; new-content privacy checks passed.

This is an unsigned Windows test candidate. Live two-monitor behavior, audio, Wacom, colour and device-session acceptance remain open. Windows 1.1.028 has no update feed or installer path, so existing installations require a one-time MSI upgrade; publishing this candidate cannot trigger an automatic update.
