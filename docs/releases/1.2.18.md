# BDE fernweh 1.2.18

The Linux Host supports administrator assistance without waiting for desktop-owner
approval. Administrators configure an explicit OS group through
`collaboration_support_group`; the setting is disabled by default. Membership
comes from the authenticated account, never a client-provided role.

Support participants are shown in the desktop indicator. Owner consent controls
cannot block their access, and a missing helper does not prevent support. Normal
authentication and workstation policy still apply. Locks, logout, desktop changes
and primary stream termination end access. Support shares the existing layout
and retains guest restrictions on files, clipboard and devices.

Ordinary guests still require approval. New requests preserve the input pause
while owner permission controls are open. Desktop revocation continues even
when the local consent channel cannot open.

This is a Host-only release; existing collaboration-capable clients use the same
request/status/launch protocol. Client update feeds are unchanged. Package and
workstation verification are recorded separately; these notes do not claim
unperformed hardware acceptance.
