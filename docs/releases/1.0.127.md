# PLANK 1.0.127 (bde fork) — BDE Fernweh Client

## Changes

- The Mac Client is named **BDE Fernweh Client** and opens on Remote access
  (sign in through `remote.bde.run`); LAN workstations stay one click away
  ("Local workstations"). Internal identifiers are unchanged, so settings,
  remembered sessions and Touch ID keys carry over (best-day-ever/plank-client#9).
- The remote-access session is remembered across restarts on macOS (login
  Keychain, this device only; token and user name only). The broker's session
  lifetime still applies.
- Remote workstations: display setup asked on first connect and saved per
  workstation (plank-client#8); brokered launch accepts the host's upper-case
  transport digest (plank-client#8); one request per host connection
  (plank-client#6).
- Linux packaging gates and the DMG use the new display name.

## Packages

- macOS Client: macOS 13+, Apple Silicon, signed/notarized DMG, built from
  main on the local Mac builder (GitHub Actions unavailable).
- Other packages are not rebuilt for this version.
