# Fernweh 1.2.30 — Linux NVENC lifecycle candidate

Direct Linux CUDA NVENC sessions finish teardown on the thread that owns their
CUDA binding. Every session retains its own primary-context reference and drains
conversion work before releasing its registered input surface. Partial failed
conversions drain before the caller can release their borrowed source frames. This addresses a
session-recreation defect that could crash a media worker during a fresh login or
display modeset. Driver and kernel pins are unchanged.

The context-owner regression suite is included in the native Host package gate.
Hardware acceptance must use the identical RPM and check for hidden worker
restarts as well as restored video. Package compilation alone does not close
fresh-login, sign-out, reconnect or repeated-modeset acceptance.

No Client or broker behavior changes are required. Release-feed publication and
platform package promotion follow exact-artifact hardware acceptance.

See [the lifecycle contract](../development/nvenc-cuda-lifecycle.md).
