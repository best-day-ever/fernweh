# BDE Fernweh 1.2.20 — workstation access authorizes collaboration

The Linux Host can allow every authenticated user with access to the workstation
to join its current unlocked desktop without owner approval. Set
`collaboration_require_approval = false` in the administrator-owned Host config.
The default remains owner approval for installations that do not opt in.

Automatically authorized participants receive interaction access and remain
visible to the owner. Owner deny, downgrade, revoke and helper closure cannot
block their admission. Authentication, workstation authorization, desktop locks,
logout, grant expiry, guest-channel restrictions and existing display layout
remain enforced. The participant indicator uses a neutral authorized-access label.

This is a Host-only release; no Client or broker update is required. Qualification
and exact-package deployment evidence belong with the selected platform pin.
