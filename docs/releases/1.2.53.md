# Fernweh 1.2.53 candidate

- A new connection waits briefly when a Linux workstation is still closing the
  previous stream. An actual competing session still requires the existing
  confirmation before it can be transferred.
- Windows restores the saved-settings review and stream benchmark. The review
  can use automatic video for one connection while keeping saved settings.
  Automatic video tries hardware 4:2:0 profiles first on the relay and still
  checks the exact decoder and display mode before launching.

This candidate includes the 1.2.52 QUIC receive-buffer update. Native package
and live session qualification determine promotion.
