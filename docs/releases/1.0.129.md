# PLANK 1.0.129 (bde fork) — BDE Fernweh first sign-in, pointer fix, display fit, remote quality settings

## Changes

- Mac Client, pointer input (best-day-ever/plank-client#14): the mouse, clicks, scroll, pen/tablet and the
  remote cursor follow the drawable the renderer actually letterboxes into. Fixes the offset after entering
  or leaving native fullscreen, resizing the window or switching the Mac's display mode (a regression since
  1.0.120: input used a layout captured before the asynchronous Spaces transition finished, up to ±54 px at the
  edges of a 1080p stream, and clicks near the top and bottom of a windowed stream were dropped).
- Mac Client, displays (plank-client#17): one probe for the Mac's panel, desktop and native-fullscreen viewport
  feeds the Display dialog and the stream. "Match my display" no longer fails on odd panels: it picks the closest
  supported mode (a 14-inch MacBook Pro in its default mode streams 2560x1600 into the 3024x1890 viewport below
  the camera housing, without bars). The dialog shows what the Mac really is, e.g. "3024 × 1964 display, desktop
  1920 × 1200 (1×)".
- Mac Client, notch-safe laptop mode (plank-client#20): "Match my display" on a 14-inch MacBook Pro streams 1:1
  at 3024x1890, the fullscreen area below the camera housing, when the workstation host advertises feature
  `0x4000000`; older hosts fall back to the fitted 2560x1600.
- Mac Client, Remote quality settings (plank-client#18): every workstation reached through the broker has a
  "Settings…" dialog with Display and Stream quality (capture source, encoding profile, bitrate on the office
  network and over the internet), plus "Remote access defaults" in Settings. Default: NVENC HEVC 10-bit 4:4:4
  identity at 50 Mbps. A choice the workstation cannot encode opens the dialog instead of being replaced
  silently. PLANK workstations always stream at 60 fps, and the Frame rate setting now says so.
- NVENC 4:2:0 bandwidth profiles for slow links: H.264 8-bit 4:2:0 and H.265 10-bit 4:2:0 — NVENC (low
  bandwidth), NvFBC only, needs Linux host 1.0.128 (already pinned); BT.709 limited range, VideoToolbox hardware
  decode (plank-client#12, plank-host-linux#4).
- Welcome to BDE Fernweh (plank-client#19, broker in this release): a first-launch wizard for remote people. An
  administrator creates the account with a one-time password and grants Fernweh remote access; the person then
  sets their own password, adds an authenticator app (QR code in the Client) and optionally Touch ID, and is
  signed in, without the studio's LAN-only portal. The broker enforces the gates (bde-linux
  `docs/plank-broker.md` §16): Fernweh entitlement with the OTP auth type, not an administrator, no second factor
  yet, a one-time password issued within 7 days, rate limits, audit; the session is only ever minted by a normal
  password + authenticator login.
- Broker (`apps/broker`): enrolment API `/v1/enroll/*` (additive to contracts v1), reading its gates with the
  broker's own read-only IPA permissions and writing the token and passkey as the user; an unlocatable KDC or
  kpasswd server now counts as unavailable, never as a failed password.
- File clipboard (best-day-ever/plank#22, default off) is included; its common-c commits now come from
  best-day-ever/plank-common-c (plank-client#15, plank-host-linux#6).

## Packages

- macOS Client 1.0.129: macOS 13+, Apple Silicon, signed and notarized DMG, built from `bde/main` on the local
