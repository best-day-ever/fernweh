# BDE Fernweh 1.2.19 — first-notch scrolling on Linux

The Linux host now addresses its owned virtual mouse for absolute X11 motion,
buttons and scrolling. Moving the pointer and then scrolling no longer switches
between the core XTEST pointer and the uinput mouse, which could consume the first
notch as a new scroll baseline in GTK and Qt applications. Zero-distance baseline
events preserve the first real wheel report without adding a synthetic notch.

Both axes retain their original high-resolution reports and legacy-detent
accumulation. Exact desktop coordinates and uinput button delivery are preserved.
Devices that cannot support the addressed XInput path retain the previous fallback.

This is a Host-only release. Client update feeds and broker binaries do not
change. Native application qualification and package evidence are required before
publishing the workstation package pin.
