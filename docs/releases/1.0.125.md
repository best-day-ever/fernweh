# PLANK 1.0.125 (bde fork)

## Changes

- Remote access broker: office clients get a direct route. A `connect` from a
  network in `routing.direct_client_cidrs` answers `route: "direct"` with the
  workstation's own address and port instead of a relay lease; sign-in, host
  assignment and GSSAPI admission are unchanged (best-day-ever/plank#7).
- macOS Client: parses and logs the brokered route (plank-client#4).
- macOS Client runs on macOS 13 or later (Qt 6.10.2 floor) instead of only
  macOS 27. The deployment target is one setting,
  `PLANK_MACOS_DEPLOYMENT_TARGET`, and the DMG gate checks every Mach-O's
  `minos` against it (best-day-ever/plank#8, plank-client#5).

Linux Host, Linux Client and transport behavior are unchanged.

## Packages

- macOS Client: macOS 13+, Apple Silicon, signed/notarized DMG, rebuilt from
  main on the local Mac builder (GitHub Actions unavailable).
- Linux Host / Linux Client / macOS Host: not rebuilt for this version.

## Validation scope

A full Client build at deployment target 13.0 produced no availability
warnings; every dependency dylib and the executable declare `minos 13.0`.
All gated Client suites pass. Launch on a real macOS 13–26 machine is the
remaining acceptance check.
