# 1.1.043 — reserved local session controls

This is a Client-only release. Host and broker updates are not required.

- **Ctrl+Alt+Shift+Q** always disconnects the focused session, including in
  immersive keyboard mode and while reconnecting.
- **Ctrl+Alt+Shift+T** always toggles the stream toolbar. On a Mac, use
  **Control+Option+Shift** for the modifier keys.
- On macOS, these controls are intercepted by the native keyboard tap before
  ordinary input reaches the remote queue. They still work when that queue is
  full or its SDL wake event cannot be queued. Local control requests use
  explicit session state, with disconnect taking priority over toolbar toggles.
- Disconnect releases keyboard and mouse capture and hides stream windows
  before waiting for reconnect or reachability workers to finish.
- Shortcut letter releases stay local, even when modifiers are released first.
  Key repeat cannot toggle the toolbar repeatedly. Other immersive shortcuts
  still go to the remote desktop; **Ctrl+Alt+Shift+Z** retains its escape behavior.

The controls apply while a stream window owns keyboard focus. They do not
intercept typing in other applications. macOS protected system shortcuts and
Accessibility permission requirements remain unchanged. No application shortcut
can recover an operating-system freeze or bypass denied OS input permissions.

The shared shortcut policy and native macOS queue/focus behavior have automated
regression coverage. Linux and Windows build gates include the shared policy
suite; this release distributes the Apple Silicon Mac Client.
