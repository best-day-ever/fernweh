# 1.1.027 — Launcher polish

Client-only release. The Linux Host stays at 1.1.025.

- **Dialogs** sit on one surface: the title and button row no longer show a
  band in another shade. A modal dialog darkens the window behind it instead
  of washing it out in grey, the confirming action is the one filled button
  (red when it signs someone out), and it says what it does: Add, Save,
  Save and connect, Sign in, Remove.
- **Authenticator code** fields keep their "6 digits" hint inside the field
  instead of moving it onto the border.
- **Remote workstations** explain why one cannot be used ("its identity
  changed; ask the studio to check it") and no longer read "Offline ·
  offline". An empty list says what to do. Sign-in progress has its own line.
- **Settings**: the remote access quality controls fit their column, the
  server fields (broker, port, key pins, Touch ID domain) have their own
  "Remote Access Server" section, the two restore buttons say what they
  restore, and the QUIC payload shows 1344 instead of "1.344".
- **Displays**: the first sign-in's screen step fits its card; the display
  setup dialog is only as tall as it needs to be.
- Local workstations have a title and show "In Session" in amber, as in the
  remote list; "PC" is "workstation" throughout; icon buttons and sign-in
  fields have names for VoiceOver; the permission and changelog dialogs say
  BDE fernweh.
