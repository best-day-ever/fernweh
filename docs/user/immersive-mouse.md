# Immersive mouse mode

During a session, use the toolbar's mouse button or **Ctrl+Alt+Shift+M** to
toggle immersive mouse mode. Use the same shortcut to release the mouse.
The mode starts off each time you connect.

Enable it for Blender, Unreal Engine and other applications that wrap or
recenter their pointer. Movement continues beyond the local display edges,
including tools started with a keyboard shortcut. Mouse buttons and scrolling
continue working; releasing a mouse button leaves the mode on.

Switch it off to move between local applications. Fernweh restores ordinary
pointing after the Host confirms its current pointer position. Switching
applications, losing session focus, reconnecting, changing display layout or
using a tablet also releases capture. Release any held mouse buttons before
enabling the mode.

This candidate supports the Mac Client with an X11 Linux Host. Both ends must
support the feature; an older Host or a shared guest session does not offer
the toggle. Installed application acceptance is still pending.
